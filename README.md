# Eliza Cesista Portfolio

Personal professional portfolio for Eliza Marie Cesista, CPA (Philippines), US CMA, and MBA.

## Local development

```bash
corepack enable
pnpm install --frozen-lockfile
pnpm dev
```

## GitHub Pages

The site is configured for repository Pages at `https://elirie00.github.io/portfolio/`. Pushing to `main` runs the deployment workflow after GitHub Pages is enabled with the **GitHub Actions** source.
