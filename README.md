# Eliza Cesista Portfolio

Personal professional portfolio for Eliza Marie Cesista, CPA (Philippines), US CMA, and MBA.

## Local development

```bash
corepack enable
pnpm install --frozen-lockfile
pnpm dev
```

## GitHub Pages

The site is configured for repository Pages at `https://elizacesista.github.io/portfolio/`. Pushing to `main` runs the deployment workflow after GitHub Pages is enabled with the **GitHub Actions** source. To publish at `https://elizacesista.github.io/` without the `/portfolio/` path, the repository would need to be named `elizacesista.github.io`.
